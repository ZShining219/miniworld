## 2. 修正的偏移

v0.6 曾把“一次经授权的真实远端模型调用”列为 Demo 冻结强制条件。用户确认的是“本地优先，允许受控远端 AI”，同时明确要求先完成 Demo、暂不纠结若干模型细节。因此：

- 保留 OpenAI Responses Provider、结构化 schema、数据最小化、配置门和审计能力；
- 保留真实远端模型作为用户授权后的可选验证；
- 不再用未选择的 Provider、模型或数据类别阻塞本地 Demo；
- 不把确定性 Provider 冒充真实模型，界面和记录继续标注 `demo`。

这项修正没有删除用户要求的能力，也没有缩小三个产品闭环；它只移除了技术方案自行增加的完成门。

## 3. 完成审计结论

当前证据证明：用户要求的三个闭环、地址两步策略、直线距离、手动三类材料、日报/周报、定时公开读取、外部写入确认边界、本地部署、线性前端、README、测试记录和 Git 管理均已完成。真实个人地标、长期公司来源、远端模型、最终视觉、tag 和公开 push 属于用户醒后的配置或发布决策，不是当前可拉起 Demo 的缺口。
